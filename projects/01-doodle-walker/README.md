# Doodle walker / 낙서에 관절을 붙이면

A three-legged rigid-body creature drawn as a white pen doodle. Pymunk computes contacts and motor-driven joints; a seeded random parameter search tests **192 candidates** (baseline plus191 samples). The best sampled candidate moves about593.26 simulation units, versus2.27 baseline, measured after the initial0.5s settling period. This is a finite motor-parameter search, not neural-network training or arbitrary sketch recognition.

`search.py` writes `metrics.json` (all trials) and `frames.json` (selected trajectories). `render_clean.py` writes `first-clean.mp4` and `result-clean.mp4`, matching the latest doodle visual revision. Physics runs at120Hz for7seconds, recorded at30fps. Each8second render contains7seconds of physics followed by1second holding its final recorded frame; the last second is not an additional simulated motion. The camera follows the body without changing its physical states.

Change search ranges or random seed in `search.py` to try other gaits. The body shape and three joints are explicitly authored, not extracted from an input image. The metal engine illustration and narrated explanation are excluded from this runnable simulation package.

## Run locally

Python 3.12 recommended. Install FFmpeg and make `ffmpeg` available on PATH (macOS: `brew install ffmpeg`; Ubuntu: `sudo apt install ffmpeg`; Windows: install FFmpeg and add its bin directory to PATH).

From this project directory:

```sh
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows PowerShell instead: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python search.py
python render_clean.py
```

No API key, account, GPU, network service, or downloaded model is required after dependency installation. Generated MP4 files are silent experiment renders, not the narrated promotional Short. Renderers draw recorded simulation states with Pillow and encode H.264 using FFmpeg. Any labels use Pillow's bundled font, with no system font dependency. Floating point results can vary slightly by platform.

## Provenance and dependencies

Authored simulation and renderer code from the corresponding Siljangnim Shorts experiment. `provenance.json` records original source hashes and packaging changes. Recorded JSON is supplied for inspection and can be regenerated by the commands above.

Dependencies: Pymunk (MIT), Pillow (HPND). FFmpeg is an external executable with LGPL/GPL terms depending on its build; its binary is not included. Dependency source and licenses remain with their upstream distributions.
