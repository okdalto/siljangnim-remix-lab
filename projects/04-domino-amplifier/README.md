# Domino amplifier / 작은 도미노로 큰 도미노를 쓰러뜨리면

The same initial angular-velocity impulse is applied to the first domino. Direct contact with a much larger domino fails. Adding six intermediate sizes lets a chain of eight fall. Each next piece is1.35times taller: the last is **8.172times taller**, not8times the mass. Mass scales with 2D area, giving66.784times the first mass. Gravity supplies the falling energy; this is not energy creation.

Pymunk tests24 ratio/gap combinations (three ratios and eight gaps), then selects ratio1.35/gap0.35. The source explicitly requires this demonstrated candidate to succeed; it does not automatically pick a largest ratio. `metrics.json` records all tests; `states.json` records the10second before/after simulations at30fps from a120Hz solver. `render.py` exports `before-clean.mp4` (4seconds), `after-clean.mp4` (7seconds), combined `preview.mp4` (11seconds), and a contact sheet. Render timing is1x; the camera zooms out to keep the large falling piece in frame.

Change ratios, gaps and selection in `search.py` for a different chain. This is an authored2D rigid-body model with fixed friction and no material deformation; the tested scale relationship is not a universal limit for real dominoes. Pips are visual marks attached to the same rigid transforms.

## Run locally

Python 3.12 recommended. Install FFmpeg and make `ffmpeg` available on PATH (macOS: `brew install ffmpeg`; Ubuntu: `sudo apt install ffmpeg`; Windows: install FFmpeg and add its bin directory to PATH).

From this project directory:

```sh
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows PowerShell instead: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python search.py
python render.py
```

No API key, account, GPU, network service, or downloaded model is required after dependency installation. Generated MP4 files are silent experiment renders, not the narrated promotional Short. Renderers draw recorded simulation states with Pillow and encode H.264 using FFmpeg. Any labels use Pillow's bundled font, with no system font dependency. Floating point results can vary slightly by platform.

## Provenance and dependencies

Authored simulation and renderer code from the corresponding Siljangnim Shorts experiment. `provenance.json` records original source hashes and packaging changes. Recorded JSON is supplied for inspection and can be regenerated by the commands above.

Dependencies: Pymunk (MIT), Pillow (HPND). FFmpeg is an external executable with LGPL/GPL terms depending on its build; its binary is not included. Dependency source and licenses remain with their upstream distributions.
