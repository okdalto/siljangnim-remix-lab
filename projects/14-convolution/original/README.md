# Convolution · PyOpenGL

인스타 릴스용 9:16 세로 캔버스의 중앙 정사각형 영역에서 컬러 사진 → RGB intensity 분리 → 3×3 곱셈·합산 → Sobel 결과를 보여줍니다. UI와 창 테두리는 표시하지 않습니다.

## 실행

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python convolution.py
```

기본 입력은 `assets/dog.jpg`입니다. 다른 이미지는 `--image photo.png`로 지정하거나 창에 드롭합니다. 중앙 정사각형으로 crop하여 계산용 32×32 RGB 데이터와 시작 장면용 512×512 텍스처를 만듭니다. 시작 사진과 박스화된 이미지는 원본 RGB 색이며, 초기 필터는 RGB 색 표식을 사용합니다. 채널 분리 시작 직후 0.12초 안에 흑백 intensity로 전환하고 계산에는 RGB 채널을 유지합니다.

## 모양과 모션

- 모든 픽셀·필터·출력은 가장 짧은 반쪽 길이의 12%만 모서리를 둥글게 다듬은 SDF 박스입니다.
- 합산 결과와 이동 중 결과도 원본과 동일한 반쪽 크기 `(0.0783, 0.0783, 0.065)`를 유지합니다. 필터 박스에도 별도 크기 축소를 적용하지 않습니다.
- 박스의 법선·깊이를 RGBA16F 텍스처에 기록하고 `box_outline.frag`에서 얇은 흰색 모서리·실루엣을 검출합니다. 선 레이어에 합성하여 화면 해상도 기준으로 얇은 두께를 유지합니다.
- 곱셈 접근 중에는 표면 사이에 약 0.07의 z축 간격을 유지합니다. 가로 정렬을 끝낸 뒤 합체 진행도의 마지막 35%에서만 깊이 간격을 닫고, 닫힘 스프링의 오버슈트는 제한합니다.
- 합체 중에만 smooth union으로 표면이 연결됩니다. 최종 결과는 다시 같은 모서리 반경의 고정된 박스가 됩니다. 메타볼 강도는 초기 강화 버전의 85%입니다.
- 원본 픽셀은 이동이 시작되면 기존 위치에서 사라집니다. 해당 픽셀의 돌출 이동이 완료된 뒤 0.08초 후, 원래 자리에서 0→1 스케일 스프링으로 0.5초 동안 재생성됩니다. 빈자리에서는 남은 픽셀과 영역 바깥 경계의 거리를 계산해 뒤쪽 채널이 올바르게 보이게 합니다.
- 필터 박스는 픽셀의 추출 경로를 따라가지 않고 별도의 부유 위치에 대기합니다. 픽셀이 올라온 뒤 곱셈 단계에서만 만납니다. 가속 초반 작업 공간은 이미지 스택 앞쪽으로 배치하여 다른 채널의 이미지 평면도 관통하지 않습니다.
- 처음 두 설명 연산에서는 결과 이동 시작 0.25초 후 다음 필터를 현재 카메라 왼쪽 화면 밖에서 미리 생성합니다. 1.5초의 스프링 경로로 다음 대기 위치에 도착하며, 다음 연산 시작 시 위치·크기가 그대로 이어집니다. 빠른 스캔 구간은 기존의 동시 연산·점진적 모션 생략을 유지합니다.
- 실제 필터 박스가 이미지의 박스화가 끝난 뒤 옆에서 나타나 대기하며, 확대 중에는 작업 공간 옆으로 이동합니다. 필터와 추출한 픽셀은 원본과 같은 0.18 픽셀 간격과 크기를 유지합니다. 필터 채널도 이미지 채널과 동시에 분리됩니다. 확대 대기 위치의 가로 간격은 0.66, 깊이 간격은 0.24입니다. 곱셈 단계에서만 픽셀 위로 접근하여 합쳐집니다. 카메라는 대기 중인 필터까지 포함해 확대합니다.
- 3×3 영역의 네모 테두리는 별도 RGBA 프레임버퍼에 `GL_LINES`로 그립니다. 월드 좌표를 현재 카메라의 뷰 좌표로 투영하며 SDF 볼륨은 만들지 않습니다. 장면의 raymarch 깊이 텍스처를 공유해 뒤쪽 선을 가린 후, 투명 선 레이어를 합성합니다.
- 이미지와 필터 아래에 자간을 넓힌 Andale Mono 고정폭 서체로 `IMAGE`, `FILTER`를 표시합니다. 이전 크기의 약 70%이며, 이미지·필터와 같은 월드 XY 평면에 놓여 쿼터뷰의 기울기와 축소를 따릅니다. 박스화된 이미지와 필터 등장 후 잠깐 표시하고 채널 분리가 시작되기 전에 사라집니다.
- 채널은 쿼터뷰에서 x/y 좌표를 유지하며 z축으로 분리됩니다. 채널 간격은 0.95입니다.
- 돌출과 이동은 감쇠 질량-스프링 응답으로 계산합니다. 돌출에는 약 5.4%, 분리에는 2.5%, 합산에는 1.5–2%의 작은 오버슈트를 적용합니다.
- 마지막 결과는 카메라가 정착한 뒤 1.65초 동안 원본 컬러 사진으로 크로스페이드됩니다. 실제 시작 장면을 별도 프레임버퍼에 캐시해 합성하며, 끝과 반복 시작 프레임의 픽셀값이 같습니다. 자동 반복 때는 등장 페이드를 생략합니다. 이미지 교체 시 캐시도 갱신합니다.
- 마지막 결과의 전면 네 모서리는 처음 사진과 같은 화면 좌표에 놓입니다. 30×30 결과의 실제 외곽 크기로 카메라 배율·초점·깊이를 계산하고, 이전 입력 채널은 왼쪽으로 퇴장시킵니다. 픽셀 자체 크기는 유지합니다.
- 카메라는 박스의 뷰 공간 투영 경계를 샘플링해 장면별 고정 구도를 정합니다. 곱셈·합산 중에는 첫 번째와 두 번째 연산 모두 같은 확대 구도로 완전히 멈추며, 나머지 픽셀을 훑는 동안에는 전체 구도를 고정합니다. 배경 이미지는 확대 화면 밖에 허용하며 숨겨서 준비하는 다음 필터는 구도에 포함하지 않습니다.
- 장면 경계에서만 이동과 줌에 같은 quintic easing을 적용합니다. 반동·스프링·픽셀 추적을 카메라에 적용하지 않습니다. 연산 확대 진입은 2.3초, 결과 이동과 전체 보기 전환은 1.95초, 마지막 결과 보기 전환은 3.4초입니다. 결과 픽셀 이동도 반동 없는 easing으로 맞췄습니다.
- 필터 등장 전에는 원본 이미지만 중심에 놓습니다. 등장 시 2.2초 동안 전체 구도로 연결하며, 필터가 처음 나타나는 짧은 구간은 12px 이상의 여백, 이후에는 중앙 720px 영역에서 43.2px 이상의 여백을 검사합니다.
- 경로를 120 Hz로 계산하고 위치·속도·가속도가 연속인 quintic 보간으로 샘플링합니다. 시작과 끝의 사진 위치·배율도 일치합니다.

## 연산 순서

1. 이미지가 나타나고 1.1–2.3초에 박스화됩니다. 2.5초부터 옆에 3×3 필터가 나타납니다. 3.45초부터 영어 라벨이 나타나고, 완전히 나타난 뒤 0.8초 대기하고 4.65–5.05초에 사라집니다.
2. 5.1–6.3초에 RGB intensity 평면을 분리합니다. 분리 후 선으로 그린 3×3 영역 표시가 나타납니다.
3. 7.3초부터 처음 두 위치를 각각 8.10초 동안 확대하여 설명합니다. 각 채널의 9개 픽셀이 순서대로 돌출되고 필터 값들이 왼쪽 위부터 순서대로 접근해 합쳐집니다. 값마다 0.045초, 채널마다 0.018초의 시차를 두며, 마지막 값의 합체가 끝난 뒤 전체 합산을 시작합니다. RGB 전체 27개 결과가 채널별 중간 박스를 거치지 않고 하나의 출력 박스로 시차를 두고 모입니다. 합산 출발 시차는 값마다 0.035초, 채널마다 0.012초이며 전체 합산 구간은 1.9초입니다.
4. 처음 두 결과만 출력 이미지로 이동하여 저장합니다. 결과 이동은 1.8초이며, 도착하면 별도 대기 없이 다음 연산을 시작합니다.
5. 세 번째 위치부터도 가속 초반에는 입력 영역에서 돌출·곱셈·27→1 합산을 보여줍니다. 출력 위치로 날아가는 모션은 생략합니다. 실제 재생 간격이 0.24초 이상이면 연산 모션을 그대로 표시하고, 0.075초 이하로 빨라지면 완전히 생략합니다. 사이 구간은 quintic easing으로 작업 박스의 크기와 돌출량을 줄여 자연스럽게 사라지게 합니다. 이후에는 결과 박스만 바로 나타납니다.
6. 왼쪽 위부터 매 줄을 왼쪽→오른쪽으로 처리한 후 다음 줄의 왼쪽으로 내려갑니다. 지그재그로 움직이지 않습니다. 나머지 898개 위치는 처음 약 0.35초 간격으로 시작합니다. 속도의 로그값에 quintic easing을 적용하여 4초 동안 점진적으로 최고 속도(위치당 0.004초)까지 가속합니다. 초반 간격은 0.348→0.322→0.267초입니다. 최고 속도를 잠깐 유지한 후 마지막 2.8초 동안 quintic 속도 감쇠로 0까지 감속합니다. 가속·정속·감속 전체는 약 7.72초입니다. 느려지는 후반에는 영역 프레임 이동을 셀 간격 전체에 걸쳐 분산해 짧은 튐을 줄입니다.
7. 마지막 픽셀에 도착한 뒤 0.35초 정지하고 완성된 30×30 결과로 카메라가 이동합니다. 영역 선은 0.6초 동안 사라집니다. 1배속 타임라인은 약 37.6초이며 자동 반복합니다. 기본 재생은 사용자가 선택한 0.80배속으로 약 47.0초입니다. `--speed 1`로 1배속 재생할 수 있습니다.

RGB 전체 27개 결과를 하나의 exponential soft minimum 필드로 합칩니다. 평가 순서에 따른 변형을 방지하고 겹친 부피를 연속적으로 보정하여, 최종적으로 정확히 하나의 박스에 수렴합니다. 색도 같은 가중치로 섞습니다. 스프링의 오버슈트가 메타볼 부피를 불필요하게 늘리지 않도록 위치와 필드 정규화를 분리합니다. 저장된 출력은 합체 계산에 참여하지 않습니다.

확대 장면은 Gx의 곱셈·합산을 표현합니다. 실제 출력은 NumPy에서 모든 위치의 Gx/Gy를 계산하여 휘도 응답을 합친 에지 크기입니다. 필터 밝기는 계수의 절댓값을 표현하며 +/− 부호는 계산에 유지합니다. 결과 표시 밝기는 검정 박스도 보이도록 `0.12 + 0.82 × 출력값`입니다.

## 조작과 검증

| 입력 | 동작 |
| --- | --- |
| Space | 재생 / 일시정지 |
| R | 처음부터 재생 |
| 1–5 | 사진 / RGB / 필터 / 확대 연산 / 결과 |
| ← / → | 1초 이동 |
| Escape | 창 닫기 |

```sh
python convolution.py --self-test
python convolution.py --loop-merge --speed 0.65
python convolution.py --capture merge.png --time 10.8 --paused
python convolution.py --capture result.png --time 38 --paused
python convolution.py --benchmark --time 29.3 --paused
python tools/measure_motion.py
python tools/audit_framing.py --samples 3001 --check
```

`--loop-merge`는 곱셈 직전부터 RGB 전체 27개 결과가 하나로 모이는 직후까지 반복합니다. 결과를 날려 보내는 부분은 제외합니다. 단계 키 1–5를 누르면 반복 모드를 종료합니다.

창은 화면 높이에 맞춘 9:16 세로 비율입니다. 내부 raymarch는 기본 720×720을 유지하고 위아래에 각각 280px의 배경 여백을 추가하여 720×1280으로 표시·캡처합니다. 기존 구도와 모션은 정사각형 영역 안에서 유지됩니다. `--resolution 1080`이면 1080×1920으로 캡처합니다. OpenGL 3.2 이상과 GUI 디스플레이가 필요하며, 수치 테스트는 디스플레이 없이 실행할 수 있습니다.

`tools/measure_motion.py`는 렌더러와 같은 스프링·추적 카메라로 구간마다 1,201회 경로를 샘플링해 화면상 최고 속도를 측정합니다. 결과는 `motion_metrics.json`에 저장합니다. 스프링은 프레임당 한 번 계산하여 GPU에 전달합니다.

## 계산

각 RGB 채널에 Gx/Gy를 적용하고 `.2126R + .7152G + .0722B`로 휘도 응답을 합칩니다. 결과는 `clip(sqrt(Gx² + Gy²)/4, 0, 1)`입니다. valid, stride 1이므로 32×32 입력의 결과는 30×30입니다. 입력 sRGB를 선형광으로 변환하지 않습니다. 일반적인 Sobel cross-correlation 방향이며 수학적 convolution의 커널 반전을 적용해도 최종 magnitude는 같습니다.
