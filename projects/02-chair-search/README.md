# Chair leg search / 흔들리는 의자의 다리를 바꾸면

A rigid 2D chair receives two falling blocks under the same conditions for every design. Pymunk evaluates **21 combinations** of leg spread and horizontal bias. The baseline (spread12,bias0) tips approximately68.47degrees after5seconds. The selected design (spread70,bias0) stays nearly level with both loads on the seat. The score includes tilt, fallen-load penalties and a small spread penalty; this is the best of the tested set, not a globally optimal chair.

`run.py` writes `search.json` (all21 trajectories), `metrics.json`, and a13second labeled comparison `preview.mp4`. `clean_results.py` reruns the baseline and winner for10seconds at120Hz, exporting `clean-failure.mp4`, `clean-result.mp4`, and matching `*-trajectory.json` at30fps. These are the latest clean sources used by the Short. Only camera framing differs between failure and result; simulated conditions are unchanged. The labeled overview includes candidate inspection frames and a final hold; use clean clips for continuous1x simulation.

Change spread/bias arrays in `run.py` to search more designs. The clean renderer's selected parameters are explicit: update those if you choose a new winner. This is rigid-body contact, not a furniture safety model: bending, joint fracture, material strength and 3D stability are absent.

## Run locally

Python 3.12 recommended. Install FFmpeg and make `ffmpeg` available on PATH (macOS: `brew install ffmpeg`; Ubuntu: `sudo apt install ffmpeg`; Windows: install FFmpeg and add its bin directory to PATH).

From this project directory:

```sh
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows PowerShell instead: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run.py
python clean_results.py
```

No API key, account, GPU, network service, or downloaded model is required after dependency installation. Generated MP4 files are silent experiment renders, not the narrated promotional Short. Renderers draw recorded simulation states with Pillow and encode H.264 using FFmpeg. Any labels use Pillow's bundled font, with no system font dependency. Floating point results can vary slightly by platform.

## Provenance and dependencies

Authored simulation and renderer code from the corresponding Siljangnim Shorts experiment. `provenance.json` records original source hashes and packaging changes. Recorded JSON is supplied for inspection and can be regenerated by the commands above.

Dependencies: Pymunk (MIT), Pillow (HPND). FFmpeg is an external executable with LGPL/GPL terms depending on its build; its binary is not included. Dependency source and licenses remain with their upstream distributions.
